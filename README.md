# Authentication Service

Production-grade authentication service built with Node.js, Express, Prisma, PostgreSQL, and Redis. Implements JWT-based authentication with refresh token rotation, OTP verification, and comprehensive security features.

## Features

### Core Authentication
- ✅ JWT-based authentication (HS256 algorithm)
- ✅ Access tokens (15 minutes expiry)
- ✅ Refresh tokens (7 days expiry)
- ✅ Refresh token rotation
- ✅ Secure token hashing (SHA-256)
- ✅ Multi-device support
- ✅ Maximum active sessions per user (configurable)

### Security Features
- ✅ Token blacklist (Redis)
- ✅ User-wide token invalidation
- ✅ Password change invalidates all sessions
- ✅ Rate limiting (IP, device, user-based)
- ✅ OTP verification (SMS & Email)
- ✅ Bcrypt password hashing
- ✅ Account deactivation support
- ✅ Failed login attempt tracking

### Session Management
- ✅ Logout current device
- ✅ Logout all devices
- ✅ Get active sessions
- ✅ Revoke specific sessions
- ✅ Device tracking (IP, User-Agent, Device-ID)

### Microservices Ready
- ✅ Reusable authentication middleware
- ✅ API Gateway integration
- ✅ Service discovery support (Eureka)
- ✅ CORS configuration
- ✅ Request tracing

## Tech Stack

- **Runtime**: Node.js (ES Modules)
- **Framework**: Express.js
- **Database**: PostgreSQL
- **ORM**: Prisma
- **Cache**: Redis (Upstash)
- **Authentication**: JWT (HS256)
- **Password Hashing**: Bcrypt
- **OTP**: Twilio (SMS) + Nodemailer (Email)

## Installation

### 1. Clone the Repository

```bash
git clone <repository-url>
cd Authentication_Service
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Generate Secure Secrets

```bash
node scripts/generateSecrets.js --save
```

This will:
- Generate cryptographically secure JWT secrets
- Update your `.env` file with the new secrets
- Create a `.env.example` file for reference

### 4. Configure Environment Variables

Edit `.env` file with your configuration:

```env
# Server
PORT=8000
NODE_ENV=development

# Database
DATABASE_URL="postgresql://username:password@localhost:5432/expense_management_app?sslmode=require"

# Redis
REDIS_URL="redis://localhost:6379"

# JWT (generated by script)
JWT_ACCESS_SECRET=your_secret_here
JWT_REFRESH_SECRET=your_secret_here
ACCESS_TOKEN_EXPIRES_IN=15m
REFRESH_TOKEN_EXPIRES_IN=7d

# Bcrypt
BCRYPT_ROUNDS=16

# Twilio (for SMS OTP)
TWILIO_ACCOUNT_SID=your_account_sid
TWILIO_AUTH_TOKEN=your_auth_token
TWILIO_PHONE_NUMBER=+1234567890

# Email (for Email OTP)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your_email@gmail.com
SMTP_PASS=your_app_password

# Eureka (optional)
EUREKA_HOST="eurekadiscoveryserver.onrender.com"
```

### 5. Set Up Database

```bash
# Generate Prisma client
npx prisma generate

# Run migrations
npx prisma migrate dev --name init

# (Optional) Seed database
npx prisma db seed
```

### 6. Start the Application

```bash
# Development
npm run dev

# Production
npm start
```

The service will start on `http://localhost:8000`

## Using the Authentication Middleware

### In Express Routes

```javascript
import { authenticate } from './middlewares/authMiddleware.js';

// Protected route
app.get('/api/protected', authenticate, (req, res) => {
  // Access user ID from JWT
  const userId = req.user.user_id;
  
  res.json({
    success: true,
    message: 'Access granted',
    userId: userId
  });
});
```

### In Microservices

```javascript
// expense-service/app.js
import express from 'express';
import { authenticate } from 'auth-service/middlewares/authMiddleware.js';

const app = express();

// All routes in this service require authentication
app.use('/api/expense', authenticate, (req, res, next) => {
  next();
});

// Create expense (user_id comes from JWT, not request body)
app.post('/api/expense/create', async (req, res) => {
  const userId = req.user.user_id; // From JWT
  
  const expense = await createExpense({
    ...req.body,
    user_id: userId // NEVER trust user_id from client!
  });
  
  res.json({ success: true, data: expense });
});
```

### API Client with Auto-Refresh

```dart
// lib/services/auth_api_client.dart
import 'package:dio/dio.dart';
import 'package:flutter_secure_storage/flutter_secure_storage.dart';

class AuthApiClient {
  static const _storage = FlutterSecureStorage();
  static const _baseUrl = 'https://api.yourapp.com';
  
  late final Dio _dio;
  
  AuthApiClient() {
    _dio = Dio(BaseOptions(
      baseUrl: _baseUrl,
      connectTimeout: 30000,
      receiveTimeout: 30000,
    ));
    
    _setupInterceptors();
  }
  
  void _setupInterceptors() {
    _dio.interceptors.add(InterceptorsWrapper(
      onRequest: (options, handler) async {
        final token = await _storage.read(key: 'accessToken');
        if (token != null) {
          options.headers['Authorization'] = 'Bearer $token';
        }
        options.headers['Content-Type'] = 'application/json';
        return handler.next(options);
      },
      onError: (error, handler) async {
        if (error.response?.statusCode == 401) {
          final refreshToken = await _storage.read(key: 'refreshToken');
          if (refreshToken != null) {
            try {
              final newTokens = await _refreshToken(refreshToken);
              await _storage.write(key: 'accessToken', value: newTokens['accessToken']);
              await _storage.write(key: 'refreshToken', value: newTokens['refreshToken']);
              
              final requestOptions = error.requestOptions;
              requestOptions.headers['Authorization'] = 'Bearer ${newTokens['accessToken']}';
              return handler.resolve(await _dio.fetch(requestOptions));
            } catch (e) {
              await _clearStorage();
              // Navigate to login
              return handler.reject(error);
            }
          }
        }
        return handler.next(error);
      },
    ));
  }
  
  Future<Map<String, dynamic>> _refreshToken(String refreshToken) async {
    final response = await _dio.post('/auth/refresh-token', data: {
      'refreshToken': refreshToken,
    });
    return response.data;
  }
  
  Future<void> _clearStorage() async {
    await _storage.deleteAll();
  }
  
  // Auth methods
  Future<Map<String, dynamic>> login(String email, String password, String deviceId) async {
    final response = await _dio.post('/auth/login', data: {
      'email': email,
      'password': password,
      'deviceId': deviceId,
    });
    return response.data;
  }
  
  Future<void> logout(String refreshToken) async {
    await _dio.post('/auth/logout', data: {
      'refreshToken': refreshToken,
    });
  }
  
  // Generic API methods
  Future<dynamic> get(String path) => _dio.get('/api$path');
  Future<dynamic> post(String path, dynamic data) => _dio.post('/api$path', data: data);
  Future<dynamic> put(String path, dynamic data) => _dio.put('/api$path', data: data);
  Future<dynamic> delete(String path) => _dio.delete('/api$path');
}
```

### Usage in Flutter

```dart
// lib/screens/login_screen.dart
class LoginScreen extends StatefulWidget {
  @override
  _LoginScreenState createState() => _LoginScreenState();
}

class _LoginScreenState extends State<LoginScreen> {
  final _apiClient = AuthApiClient();
  final _storage = FlutterSecureStorage();
  
  Future<void> _login(String email, String password) async {
    try {
      final deviceId = Uuid().v4(); // Generate unique device ID
      final response = await _apiClient.login(email, password, deviceId);
      
      // Store tokens securely
      await _storage.write(key: 'accessToken', value: response['accessToken']);
      await _storage.write(key: 'refreshToken', value: response['refreshToken']);
      await _storage.write(key: 'userData', value: jsonEncode(response['user']));
      
      // Navigate to home
      Navigator.pushReplacementNamed(context, '/home');
    } catch (e) {
      // Show error
    }
  }
  
  Future<void> _logout() async {
    try {
      final refreshToken = await _storage.read(key: 'refreshToken');
      if (refreshToken != null) {
        await _apiClient.logout(refreshToken);
      }
    } catch (e) {
      // Ignore errors
    } finally {
      await _storage.deleteAll();
      Navigator.pushReplacementNamed(context, '/login');
    }
  }
}
```

## Security Best Practices

### 1. Environment Variables
- ✅ Never commit `.env` to version control
- ✅ Use different secrets for each environment
- ✅ Rotate secrets every 90 days
- ✅ Use secret management services in production (AWS Secrets Manager, HashiCorp Vault)

### 2. Token Management
- ✅ Access tokens expire in 15 minutes
- ✅ Refresh tokens expire in 7 days
- ✅ Refresh tokens are hashed before storage
- ✅ Tokens are rotated on each refresh
- ✅ Maximum 5 concurrent sessions per user

### 3. Password Security
- ✅ Bcrypt with 16 rounds
- ✅ Minimum 8 characters with complexity requirements
- ✅ Password change invalidates all sessions
- ✅ Failed login tracking

### 4. Rate Limiting
- ✅ IP-based rate limiting
- ✅ Device-based rate limiting
- ✅ User-based rate limiting
- ✅ OTP attempt limiting (max 3 attempts)

### 5. Token Blacklisting
- ✅ Redis-based token blacklist
- ✅ User-wide token invalidation
- ✅ Automatic cleanup of expired tokens

## Database Schema

### User Model
```prisma
model User {
  user_id         String   @id @default(dbgenerated("gen_random_uuid()")) @db.Uuid
  first_name      String
  last_name      String
  email           String   @unique
  mobile_number   String   @unique
  language        String?
  password_hash   String
  salt            String?
  isverified      Boolean? @default(false)
  isactive        Boolean  @default(true)
  failed_attempts Int      @default(0)
  last_login      DateTime
  create_at       DateTime @default(now())
  updated_at      DateTime @updatedAt
  refresh_tokens  Refresh_token[]
}
```

### Refresh Token Model
```prisma
model Refresh_token {
  token_id    String   @id @default(dbgenerated("gen_random_uuid()")) @db.Uuid
  user_id     String   @db.Uuid
  token_hash  String   @unique
  device_id   String?
  ip_address  String?
  user_agent  String?
  expires_at  DateTime
  revoked     Boolean  @default(false)
  created_at  DateTime @default(now())
  
  user        User @relation(fields: [user_id], references: [user_id])
  
  @@index([user_id])
  @@index([token_hash])
}
```

## Troubleshooting

### Common Issues

1. **Database Connection Error**
   - Check DATABASE_URL in .env
   - Ensure PostgreSQL is running
   - Verify database exists

2. **Redis Connection Error**
   - Check REDIS_URL in .env
   - Ensure Redis is running
   - Verify Redis credentials

3. **JWT Token Invalid**
   - Ensure JWT_ACCESS_SECRET and JWT_REFRESH_SECRET are set
   - Check token expiration
   - Verify token format (Bearer <token>)

4. **Prisma Migration Issues**
   - Run `npx prisma migrate reset` (WARNING: deletes data)
   - Check database permissions
   - Review migration files
